# AI Lab OSS Field Guide

[Open the public report](https://rohan-patnaik.github.io/ai-lab-oss-field-guide/)

An evidence-backed open-source contribution strategy for Rohan Patnaik. Issue-resolution revision: **19 September 2026 IST**. Repository metrics and contribution-history snapshot: **18 September 2026**.

- 32 lab and project groups; 81 retained code surfaces after removing 15 cookbook/example/content repositories from the original 96.
- Public contribution-history audit: 47 external PRs, including 14 merged.
- Six issue-resolution objectives (2 LOW, 2 MEDIUM, 2 HIGH), provisional same-repository fallbacks and a twelve-week sequence.
- Contribution policies, affiliation-adjusted external merged share, latency, queues and 31 reported failure leads across 21 repositories. Evidence and reproduction/approval gates are explicit.

## Limits

External share is the composition of merged work, **not** an acceptance probability. Hidden employment, historical affiliation and unlinked competing work remain uncertain. Some groups have fewer than three viable targets; DISCOVERY ONLY/AVOID rows explicitly mark those gaps. All issue availability must be checked again before commenting or coding. No upstream issue comments or PRs were posted during this research task.

A complaint is a discovery lead, not a verified bug. No new forum-derived bug was independently verified in this revision. Two limited checks against saved harness source are reproducible from the evidence archive; full upstream/native/GPU/Windows suites were not executed. One fallback is MEDIUM rather than LOW; another requires current repository-ownership confirmation.
