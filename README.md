# AI Lab OSS Field Guide

[Open the public report](https://rohan-patnaik.github.io/ai-lab-oss-field-guide/)

An evidence-backed open-source contribution strategy for Rohan Patnaik. Research snapshot: **18 September 2026**.

- 32 lab and project groups; 96 screened repository surfaces.
- Public contribution-history audit: 47 external PRs, including 14 merged.
- Six-PR portfolio with same-repository fallbacks and a twelve-week sequence.
- Contribution policies, affiliation-adjusted external merged share, latency, queues and issue candidates.

## Files

- [Full Markdown](report.md)
- [Standalone HTML](report.html): inline styling and JavaScript; opens locally without a server.
- [Repository metrics](metrics.json)
- [Issue audit](issues.json)
- [Evidence and collection scripts](evidence.zip): public GitHub API responses and pinned contribution/CI files. No credentials.

`index.html` and `report.html` are identical. GitHub Pages publishes the root of `main`; `.nojekyll` disables Jekyll processing. The theme toggle stores only a device-local preference. The site has no analytics, account system or external runtime dependencies.

## Limits

External share is the composition of merged work, **not** an acceptance probability. Hidden employment, historical affiliation and unlinked competing work remain uncertain. Some groups have fewer than three viable targets; WATCH/AVOID rows explicitly mark those gaps. All issue availability must be checked again before commenting or coding. No upstream issue comments or PRs were posted during this research task.
